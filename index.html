  1. Open GitHub: new fine-grained token.
  2. Name it KJayson Write page and pick an expiry date (for example 1 year).
  3. Under Repository access, choose Only select repositories and pick your site's repository.
  4. Under Permissions → Repository permissions, set Contents to Read and write.
  5. Click Generate token, copy it, and paste it below.

The key is saved only in this browser on this device. Visitors to your site never see it.
